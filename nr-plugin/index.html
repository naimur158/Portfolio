NRPlugin for Premiere Pro

A Motion Graphics Template library that lives inside Premiere Pro — browse, search, and drop templates on your timeline with one click.

Version 0.0.1  ·  Windows & macOS  ·  Premiere Pro 2023+
⬇  Download NR Plugin (.zxp)
93 MB — includes the starter template library

What it does

  • Thumbnail grid of every template, organized by category, with instant search
  • Double-click any template to add it at the playhead, on the track you choose
  • Customize colors, text and more in Premiere's own Properties panel
  • Online packs — install new template packs from inside the panel as we publish them

How to install

  1. Download the .zxp file with the button above.
  2. Get a ZXP installer (free): aescripts ZXP/UXP Installer.
  3. Open the installer and drag NR-Plugin_0.0.1.zxp into it.
  4. Restart Premiere Pro, then open Window → Extensions → NR Plugin.

Updating

Install the new .zxp over the old version the same way — your downloaded template packs are kept.
